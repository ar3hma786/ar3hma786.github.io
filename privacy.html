Privacy Policy

Last updated: November 6, 2026

This policy describes how Boltberry Studio (the "tool"), the private production tool of the YouTube channel Boltberry Circuit, handles data.

Who uses the tool

The tool is used only by the owner of the Boltberry Circuit YouTube channel. It is not offered to the public and has no other users.

What the tool does

  • Uploads the channel's own original animated videos to the owner's YouTube channel using the YouTube Data API.
  • Reads the upload status of those videos.
  • Reads the channel's own statistics (such as views and watch time) using the YouTube Analytics API, to improve future videos.

What data is accessed and stored

  • Only data belonging to the owner's own YouTube channel: video IDs, upload and processing status, and channel and video statistics.
  • The OAuth sign-in tokens that allow the tool to act on the owner's channel. These are stored encrypted (AES-256) on the owner's private server.

The tool does not collect, store or process personal information about viewers or any other people.

Sharing

No data is sold, shared or transferred to any third party. Data is used only to operate the owner's own channel.

Google and YouTube

The tool uses YouTube API Services. By using it, the channel owner is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions.

Deletion

Stored tokens and statistics are deleted when the owner revokes access or stops using the tool. Requests can be sent to the contact address below.
